ECO HOGAR v2.2 - GUIA DE PUBLICACION 24/7
=========================================

OBJETIVO
Pasar de http://localhost:3000 a una URL HTTPS para usar ECO HOGAR desde
celulares y PCs sin dejar una computadora encendida.

RECOMENDACION
Publicar el proyecto Next.js en Vercel y mantener Supabase como backend.
La aplicacion no requiere service_role en el navegador.

PASOS GENERALES
1. Guardar una copia de seguridad del proyecto y de .env.local.
2. Subir el codigo a un repositorio privado o importar el proyecto a Vercel.
3. En el hosting crear estas variables de entorno:
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
   NEXT_PUBLIC_SITE_URL=https://TU-DOMINIO
4. Desplegar.
5. Copiar la URL HTTPS final.
6. Supabase > Authentication > URL Configuration:
   - Site URL: https://TU-DOMINIO
   - Redirect URLs: https://TU-DOMINIO/**
   - Conservar http://localhost:3000/** mientras sigas desarrollando localmente.
7. Probar login, recuperación de contraseña, MFA, comprobantes y resúmenes PDF.
8. Instalar la PWA desde el celular.

NOTA SOBRE EL LECTOR PDF
La lectura de resúmenes/comprobantes PDF actualmente usa Python local desde
Route Handlers. En un hosting serverless puede requerir adaptar ese lector para
no depender de un ejecutable Python del sistema. El resto de la app está listo
para despliegue. Antes del despliegue definitivo hay que validar esa ruta en el
hosting elegido.
